# Reference videos

Place user-supplied style references under `references/<template-id>/`. Extracted frames belong in that template folder's `keyframes/` subfolder. Reference videos and extracted frames are for design analysis; they are not automatically production media or licensed assets.

Current reference folders:

- `vintage-editorial/`
- `illustrated-paper-textured/`

Use `scripts/inspect-reference.ps1 -Video <path> -Template <template-id>` to inspect a reference and save sampled frames to the selected template folder.
